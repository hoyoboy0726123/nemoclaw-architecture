      使用說明
      
    

    

      
三步驟上手

      
    
        
  1. 生成方案：左欄下拉選單或案例膠囊，一鍵生成電路＋接線＋程式碼；3D 工作台可拖曳旋轉、滾輪縮放。
    2. 
        
  2. 自由編輯（可選）：切到「自由編輯」，從元件盤放元件、用「拉線」工具點兩個孔連線。同一直排的孔彼此導通；點兩下被動元件可改規格值或切換開關。
    3. 
        
  3. 通電驗證 → 匯出燒錄：照下面的流程測試，全部正常再「匯出專案」拿 ZIP 去燒錄。
    4. 
      


      
接好線之後，怎麼驗證會不會動？

      
    
        
  1. 先看接線對不對（靜態檢查）：右欄 CHECKS 分頁——全部綠色 PASS 才算接好；紅色 ERROR 就是接錯了（未供電、短路、訊號腳懸空、缺限流電阻⋯），每一條都寫明哪個元件哪支腳出問題。自由編輯模式下工具列的 ERC 徽章也會即時顯示錯誤數。
    2. 
        
  2. 再看行為對不對（通電測試）：切到右欄 模擬 分頁按「通電 ▶」。接錯會被直接擋下並顯示原因；成功後右上角變 RUNNING。
    3. 
        
  3. 操作 INPUTS 觀察 OUTPUTS——拉動感測值滑桿或按事件按鈕，對照下表看反應：
          
      
            
    • OLED／LCD → 右欄小螢幕與 3D 板上的螢幕都會即時更新數值
      • 
            
    • LED → 紅點發光（例如光照拉到 200 以下）
      • 
            
    • 蜂鳴器 → 真的會出聲（例如溫度拉到 32°C 以上、煙霧超標）
      • 
            
    • 伺服馬達 → 指針轉到對應角度（轉旋鈕／編碼器試試）
      • 
            
    • 繼電器／水泵 → ON/OFF 切換、水滴動畫（土壤值拉到過乾）
      • 
            
    • 「👋 模擬人體經過」→ PIR 觸發 LED／警報／拍照事件
      • 
            
    • 「⬇ 按住按鈕」→ 觸發按鈕事件（開合閘門、發布訊息）
      • 
          
    
        
    4. 
        
  4. 驗證連網：MQTT 方案下方有虛擬 broker 主控台——每 5 秒會收到一筆 telemetry JSON；在指令列輸入 on / off / open / close / 90 發布指令，看繼電器、伺服有沒有聽話。
    5. 
        
  5. 實際體驗：以預設的溫濕度方案為例——把溫度滑桿拉到 35°C，OLED 立刻顯示 35.0，若接了蜂鳴器會開始鳴叫；拉回 25°C 就停。這一套行為和燒錄後的實體完全對應（相同接線、相同門檻值）。
    6. 
      

      
整套測試也可以叫助手代勞：「通電測試看看」「把溫度調到 35」「模擬有人經過」——它會回報結果，接錯時會告訴你 ERC 卡在哪。


      
工業配線模式（配電盤＋電力配電＋PLC）

      
    
        
  1. 四級範例庫（40 個）：左欄分「基礎工配（丙級）」「進階／電力配電（乙級・受電盤）」「高壓受電（11.4kV）」「PLC」五區共 55 個，點區塊標題摺疊展開。從門鈴、自保持一路到 Y-Δ、ATS 停電切換、11.4kV 受電盤、161kV/345kV 特高壓串級、PLC 輸送帶。也可以從元件盤 46 種元件自己拉線。銀色端子＝380V 主迴路、橘色＝110V 控制、紫色＝11.4kV、藍色＝161kV、粉紅＝345kV，彼此不可混接。
    2. 
        
  2. 參數都能調（雙擊元件）：馬達運轉電流、TH-RY／CO 的跳脫整定值、TR 秒數、電源線電壓、發電機起動延時——這不是展示動畫：把馬達電流調到超過整定值，保護電驛會真的熱積累後跳脫；電流表、電壓表讀值也跟著實際迴路變化。
    3. 
        
  3. 看 ERC：相間短路、缺互鎖、馬達缺相、發電機直接併市電都會直接擋下——正逆轉與 Y-Δ 的兩顆 MC 線圈一定要互串對方的 21-22 b 接點，發電機一定要經 ATS。
    4. 
        
  4. 電力公司等級演練：載入「停電自動切換」或「受電盤總和演練」，通電後按「🔌 模擬市電停電」——看發電機 AMF 自動起動、ATS 切到備用側、馬達復轉；復電後自動切回。受電盤的控制電源（TX 變壓器）取在 ATS 之後，這就是停電後控制迴路還能動的原因。
    5. 
        
  5. 高壓受電（11.4kV）：台電進線→LA→DS→VCB（或 LBS＋PF）→CT→變壓器→低壓側。牢記操作順序：送電先合 DS 再合 VCB、停電先開 VCB 再開 DS——帶載開斷 DS 模擬會真的發生弧光事故。RY51 反時限電驛（CT→電驛→VCB 跳脫）電流越大跳越快，把馬達負載或始動電流調一調就看得到差別；PF 熔絲熔斷後要到模擬面板「更換熔絲」。特高壓串級：載入「345kV E/S 超高壓變電所」看 345→161→11.4→380 四級電壓一路降到馬達；電流逐級換算（161kV 側只有零點零幾安培），保護整定要換算到該電壓等級。
    6. 
        
  6. 設備試驗（竣工／維護）：MEG 絕緣電阻、HIPOT 耐壓、CTT 變比極性、RTS 電驛注入——探棒（灰色端子）接受試設備、E/R 接 GND，到「模擬」分頁按「🧪 執行試驗」看判定。可對設備「💉 注入缺陷」練習不合格判讀。安全規則是玩真的：試驗必須停電、盤上有試驗器不可通電。
    7. 
        
  7. PLC：雙擊盤上的 PLC（或工具列「梯形圖」）開編輯器——點格子放常開／常閉接點、同一欄上下疊＝並聯、最右邊是線圈（OUT／TON 計時／CTU 計數／RST）。通電時導通的接點會亮綠色。接線規則：C1→L、C2→N 供電；COM→按鈕→X 輸入；C1→C0、Y→MC 線圈輸出。
    8. 
        
  8. 匯出：接線表、元件表、迴路圖 SVG，有 PLC 時再加 IEC 61131-3 程式（program.st）與 IO 對照表。
    9. 
      


      
變電所模式（單線圖・S/S 運轉操作）

      
    
        
  1. 是什麼：抽象層級從「端子接線」拉高到「單線圖」（一條線代表三相），練的是變電所值班員的運轉操作：停送電順序、倒母線、檢修隔離、保護協調。左欄 11 個情境分四區，點單線圖上的 CB／DS 符號就能分合閘（也可用「模擬」分頁的按鈕）。
    2. 
        
  2. 兩條鐵則（玩真的）：CB 斷路器可帶載開閉；DS 隔離開關沒有滅弧能力，只能在無電流或等電位時操作——帶載拉 DS＝弧光事故（設備損壞、要重載情境）；把 DS 合到兩個「不同的帶電系統」＝非同期併聯事故。送電＝先合 DS 再合 CB，停電反向。
    3. 
        
  3. 倒母線要領（核心科目）：先合母聯（兩條母線等電位）→ 合 B 側 DS → 開 A 側 DS（此時有並聯迴路，安全）→ 開母聯。全程不斷電，任務會即時判定。
    4. 
        
  4. 保護協調：「⚡ 注入故障」→ 主保護 CB 限時跳脫、其餘照常供電；先對主保護 CB「💉 注入拒動」再故障 → 後備保護越級跳脫、停電範圍擴大——這就是主保護／後備保護的時間協調。
    5. 
        
  5. 操作票：每一步操作（含事故）自動編號記錄，匯出含操作票 .txt、單線圖 .svg 與情境 JSON。
    6. 
        
  6. 自由建構：左欄「🏗 自由建構」或工具列開空白圖——選工具後點畫布放電源／母線／饋線；CB、DS、變壓器要點兩端（母線、節點或空白處）完成連接；「操作／排版」工具下可拖曳節點排版、點開關操作；「刪除」工具點設備移除。新裝開關一律開路，照「先 DS 後 CB」送電。注入故障時保護自動協調：離故障點最近的閉合 CB 0.5s 主保護跳脫、對它注入拒動則上一級 1.2s 越級。自建圖會自動續存，也能存進專案、匯出。
    7. 
      


      
匯出前 AI 檢查（頂欄 🔍）

      
匯出燒錄（或送電）前的最後一道簽核：按頂欄「🔍 匯出前檢查」，系統會把接線表、ERC 結果、程式碼（工業模式＝接線表＋元件表；變電所模式＝操作票）連同確定性檢查結論，送到你自己的 Google API Key（和 AI 助手共用同一把）做審查，固定回覆四段：不一致點、風險、檢查清單、預期行為。報告會以 檢查報告.md 附進匯出 ZIP；電路改過之後舊報告會標示過時，重按即可更新。

      
AI 審查屬建議性質——它是第二雙眼睛，不是執行驗證；接線對錯請以 CHECKS 分頁的確定性結果為準。


      
專案管理（頂欄 📁）

      
整個工作區（方案、自由編輯接線、工業盤面、變電所、程式碼修改、助手對話）可以「另存新專案」保存多份作品，隨時載入繼續改；也能覆存、改名、複製、刪除。專案存在這台瀏覽器裡——要備份、交作業或換電腦，用「⬇ 匯出」產生 .json 專案檔，對方按「📂 匯入」開啟。


      
燒錄後有問題？實機除錯迴圈

      
    
        
  1. 把證據帶回來：編譯錯誤訊息、序列埠輸出直接貼進助手對話；實體接線或錯誤畫面用 📎 拍照傳給助手（也可 Ctrl+V 貼上截圖或直接拖進來；照片會先壓縮，只送到你自己的 Google API）。
    2. 
        
  2. 助手診斷並動手修：接線問題會指出哪支腳；程式問題助手會直接改 main.cpp——改過的檔案在 CODE 分頁標示「⚠ 已修改」，匯出的 ZIP 用的就是修正版。
    3. 
        
  3. 重新匯出燒錄：驗證 OK 記得「📁 另存專案」保存成果；想回到原始模板按「↺ 還原模板」。改需求重新生成方案時，舊的程式修改會自動作廢以免蓋錯。
    4. 
      

      
照片判讀的極限：錯誤截圖、零件型號、明顯接錯看得出來；麵包板細部走線請以 WIRING/CHECKS 的接線表核對為準。


      
讓 AI 助手幫你做（右下角 🐾 按鈕）

      
第一次使用：點對話框右上 ⚙，貼上 Google API Key（aistudio.google.com 免費申請，金鑰只存在你的瀏覽器）。

      
一句話描述的公式：「元件／感測什麼 ＋ 條件 ＋ 動作／怎麼回報」，例如：

      
    
        
  • 「幫我做一個土壤過乾就自動澆水並用 MQTT 回報的裝置」
    • 
        
  • 「溫度超過 32 度就響蜂鳴器，OLED 顯示目前溫濕度」
    • 
        
  • 「用 ESP32-CAM 做一個偵測到人就拍照警報的門口監視」
    • 
      

      
不用寫板子型號也可以，助手會自己選。做完之後你隨時可以繼續下指令：「PIR 改接 GPIO 15」「加一顆 LED」「通電測試看看」「匯出專案」；也可以純提問（「I2C 是什麼？」「為什麼 ERC 報錯？」），助手解釋完會問你要不要直接幫你改。

      
邊做邊問也行：在自由編輯模式中求助時，助手會用小步驟幫你加元件、接線，不會蓋掉你已經接好的作品。需求超出元件庫（GPS、藍牙等）時，助手會直接告訴你目前無法實現。

      
工業模式也能叫助手：「載入 Y-Δ 範例然後通電測試」「幫我把 MC1 的 13 接到 START 的 3」「寫一個 X0 啟動、X1 停止、延時 5 秒才輸出 Y0 的梯形圖」。
