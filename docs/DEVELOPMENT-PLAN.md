## 模式一：配電盒（工業配線）— 建議先做

**目標**：台灣工業配線（丙級／乙級）教學情境——傳統電機控制，純接點邏輯、無程式。

### 元件庫
- 電源／保護：NFB 無熔絲開關、栓型保險絲、積熱電驛 TH-RY
- 控制：電磁接觸器 MC（線圈＋主接點×3＋輔助 a/b 接點）、電力電驛 MK、限時電驛 TR（ON-delay）
- 操作／顯示：按鈕 PB（a/b 接點）、選擇開關 COS、指示燈 PL（紅綠黃）、蜂鳴器 BZ
- 負載：三相感應馬達（正逆轉）、單相負載
- 配線材料：端子台 TB、線槽（裝飾性）

### ERC 規則
- 主迴路：NFB → MC 主接點 → TH-RY → 馬達 的串接完整性；缺過載保護＝警告
- 控制迴路：電壓域正確、TH-RY b 接點串入、按鈕 a/b 用法
- 互鎖檢查：正逆轉迴路缺電氣互鎖＝錯誤（會相間短路）
- 短路／未接地／浮接 沿用現有架構

### 模擬（掃描＝定點迭代）
- 按 PB → 迭代求解 → MC 吸持動畫＋咔聲 → 馬達轉動動畫、PL 亮
- 經典考題可跑：自保持啟動/停止、寸動、正逆轉互鎖、Y-Δ 延時啟動（TR 計時）、順序啟動
- 故障注入（進階）：TH-RY 跳脫模擬過載

### 產出物
- 接線表（線號對照）、元件表（BOM）、迴路圖（示意 SVG 匯出）

### Agent 擴充
- 工具：加元件到 DIN 軌、端子接線、通電測試、注入事件（按 PB、過載）
- 知識：提示詞加入配電盒要點；`get_part_info` 涵蓋工業元件

**預估規模**：≈ 自由編輯器＋模擬器的總和（最大單一功能）。可分兩批：
1. 畫布＋元件＋ERC＋「自保持」可模擬
2. 限時電驛、正逆轉/Y-Δ 全套考題、匯出、Agent 工具

## 模式二：PLC — 接在配電盒之後

**目標**：小型 PLC（台達 DVP／三菱 FX 風格，8 DI / 8 DO / 2 AI）放進同一個配電盒，外部元件沿用模式一。

### 新增內容（地基已由模式一提供）
1. PLC 本體元件：DI/DO/AI 端子、24V 電源迴路、COM 共點接法 ERC
2. **梯形圖編輯器**：常開/常閉觸點、線圈、自保持、TON 計時器、計數器（拖放、格線式）
3. 掃描週期模擬：讀輸入 → 執行梯形圖（通電路徑即時亮線）→ 寫輸出；與配電盒求解器串接（PLC DO → MC 線圈）
4. 匯出：IEC 61131-3 結構化文字（ST）＋ IO 對照表（原廠專案檔為封閉格式，不支援）
5. Agent：「幫我做按鈕自保持啟動馬達」→ 自動產生梯形圖＋接線

**方案取捨**（提問時已確認方向為完整版）：
- 方案 A（完整）：圖形化梯形圖編輯器 — 教學價值高，工程量大
- 方案 B（輕量）：規則清單（IF X0 AND NOT X1 THEN Y0）代替梯形圖 — 快但教學效果打折
